# Каталог студентов

Консольное приложение на Java 17 для итогового домашнего задания по дисциплине «Специализированные инструменты прикладного программирования». Выполнены базовый уровень и дополнительный уровень 2: собственная коллекция на динамическом массиве.

## Запуск

Нужен JDK 17 или новее; внешних библиотек и системы сборки нет. Команды выполняются в каталоге проекта:

```sh
sh run.sh
```

Скрипт компилирует исходники с `--release 17`, UTF-8 и проверкой предупреждений, затем запускает меню. В Windows можно выполнить те же команды через Git Bash либо открыть `src/main/java` в IntelliJ IDEA, выбрать JDK 17+ и запустить `catalog.Main`.

## Возможности

1. Добавление студента с консоли: имя, средний балл и номер зачётной книжки.
2. Загрузка из файла CSV или TXT.
3. Отчёт через Stream API: балл не ниже введённого порога, сортировка по возрастанию среднего балла и преобразование объектов в строки через `map()`.
4. Вывод всех записей с номерами.
5. Получение записи по номеру в списке, начиная с 1.
6. Удаление записи по номеру в списке.
0. Выход. Программа также корректно завершает работу при окончании ввода.

Пример: выбрать `2`, ввести `data/students.csv`, выбрать `3` и ввести `4`. Отчёт:

```text
Мария Соколова | средний балл: 4.20 | зачётная книжка: DEMO-003
Павел Орлов | средний балл: 4.20 | зачётная книжка: DEMO-004
Анна Смирнова | средний балл: 4.80 | зачётная книжка: DEMO-001
Ольга Волкова | средний балл: 5.00 | зачётная книжка: DEMO-005
```

При равном балле сортировка идёт по имени, затем по номеру зачётной книжки. Отчёт не изменяет порядок записей в каталоге. Данные хранятся в памяти в течение одного запуска, автоматического сохранения нет.

## Формат файла и валидация

UTF-8 (допускается BOM), обязательный заголовок, три поля через `;`:

```csv
name;averageGrade;recordBookNumber
Анна Смирнова;4.8;DEMO-001
Иван Петров;3,7;DEMO-002
```

Это простой формат без кавычек и многострочных полей. Разделитель `;` и управляющие символы внутри имени запрещены. Пустые строки пропускаются. Имя после удаления пробелов по краям не должно быть пустым или длиннее 100 символов. Балл должен быть конечным числом от 0 до 5 включительно; принимаются точка и запятая. Номер зачётной книжки состоит из 1–30 букв, цифр или дефисов и уникален без учёта регистра.

Ошибочная строка пропускается с указанием её номера и причины. Остальные корректные записи загружаются. Повторяющиеся номера пропускаются, включая повторный импорт. Если файл недоступен или заголовок неверен, импорт отменяется и существующий каталог остаётся без изменений. Файл читается через `BufferedReader` в `try-with-resources`. `data/invalid-students.csv` демонстрирует ошибки формата, диапазона и дубликаты. Все записи в примерах вымышлены.

## Структура

| Класс | Ответственность |
| --- | --- |
| `Student` | Предметная модель и валидация трёх полей |
| `DynamicArrayList<E>` | Собственный массив: хранение, расширение, вставка, `get`, `set`, `remove`, `size` |
| `StudentCatalog` | Хранение через `List<Student>`, проверка уникальности и Stream-отчёт |
| `StudentFileReader` | Чтение файла и диагностика отдельных строк |
| `ConsoleApplication` | Циклическое меню, ввод и обработка ошибок |
| `Main` | Точка входа |

`DynamicArrayList` наследует `AbstractList`, чтобы использовать стандартный контракт `List`, итератор и Stream API. Хранилище и операции реализованы самостоятельно, стандартный `ArrayList` не используется в рабочем коде. Начальная ёмкость — 4, при заполнении массив увеличивается вдвое. Удаление сдвигает хвост и освобождает ссылку на последний элемент. `modCount` обеспечивает обнаружение структурных изменений при обходе итератором. В программе доступны добавление, получение, удаление и вывод собственной коллекции.

Цепочка обработки в `StudentCatalog.report()`:

```java
students.stream()
    .filter(student -> student.averageGrade() >= minimumGrade)
    .sorted(Comparator.comparingDouble(Student::averageGrade)
        .thenComparing(Student::name)
        .thenComparing(Student::recordBookNumber))
    .map(StudentCatalog::format)
    .toList();
```

## Проверки

```sh
sh test.sh
```

Проверяются расширение и границы коллекции, 2000 воспроизводимых случайных операций в сравнении со стандартным `ArrayList`, итератор, валидация, отчёт, неизменность исходных данных, корректные и ошибочные файлы, BOM, отсутствующий файл, дубликаты и сценарии консольного меню, включая EOF. Для запуска достаточно JDK; проверка падает с `AssertionError`, если поведение расходится с ожидаемым.

## Соответствие заданию

| Требование | Реализация |
| --- | --- |
| Java 17+, ООП, минимум три поля | `Student`, разделение на шесть классов |
| Меню в цикле до выхода | `ConsoleApplication.run()` |
| Ручной и файловый ввод | `addManually()`, `loadFile()` |
| Валидация и исключения | `Student`, обработчики ошибок в меню и загрузчике |
| `try-with-resources` | `StudentFileReader.read()`, `Main.main()` |
| Хранение объектов в `List` | `StudentCatalog.students` |
| `filter`, `map`, сортировка, вывод | `report()`, `process()` |
| Собственная расширяемая коллекция | `DynamicArrayList<E>` |
| Демонстрация `add`, `get`, `remove`, `size` | Меню добавления, просмотра, получения и удаления |

Дополнительный уровень 3 с собственными алгоритмами сортировки в этот вариант не входит: по условию достаточно базового уровня и одного дополнительного.
